## Что такое тег и зачем он нужен

Тег CPMind — это небольшой JavaScript-файл (~22-24 КБ), который подключается к странице вашего сайта рядом с рекламным баннером. После подключения тег начинает незаметно наблюдать за тем, как пользователь взаимодействует с баннером:

- сколько времени баннер был виден на экране
- прокручивал ли пользователь страницу быстро или медленно
- наводил ли курсор на баннер, кликал ли
- была ли вкладка браузера активна или свернута

Когда пользователь уходит со страницы, тег отправляет собранные данные на сервер CPMind, который рассчитывает **CPMind Score** — число от 0 до 100, отражающее качество рекламного показа. Все данные доступны в панели аналитики.

**Тег не влияет на:**
- внешний вид баннера
- скорость загрузки страницы
- работу других скриптов на сайте

**Тег не собирает:**
- личные данные пользователей (имена, email, телефоны)
- cookies для идентификации пользователей
- IP-адреса

## Требования

Для интеграции тега нужно:

- Доступ к HTML-коду страницы, где размещается баннер
- HTTPS на сайте (обязательно — тег работает только через защищенное соединение)
- Любой современный браузер у пользователя: Chrome 90+, Firefox 90+, Safari 14+, Edge 90+

Специального программного обеспечения, серверных настроек или доступа к базе данных **не требуется**.

## Как выглядит интеграция

На странице нужно добавить два фрагмента кода. Первый — обертка вокруг баннера, второй — подключение тега.

**Было (баннер без тега):**

```html
<img src="banner.jpg" width="728" height="90" />
```

**Стало (баннер с тегом):**

```html
<!-- Обертка с параметрами -->
<div
  data-cpmind-creative
  data-tag-uuid="UUID_вашего_тега"
  data-campaign-id="название_кампании"
  data-creative-id="название_баннера"
  data-creative-type="banner_static"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: 728px; height: 90px;"
>
  <!-- Ваш баннер — не изменяется -->
  <a href="https://ваш-сайт.ru">
    <img src="banner.jpg" width="728" height="90" />
  </a>
</div>

<!-- Подключение тега — один раз в конце страницы -->
<script async src="https://app.cpmind.tech/tag/cpmind-tag_v{N}.min.js"></script>
```

Изменилось два момента: баннер обернут в `<div>` с параметрами, включая `data-tag-uuid` (выдается командой CPMind, привязывает показы к вашему аккаунту), и адрес скрипта содержит номер версии. Сам баннер (тег `<img>` или `<a>`) — не трогается.

## Пошаговая инструкция

### Шаг 1 — Найдите HTML-код баннера

Откройте файл страницы или шаблон, где находится баннер. Найдите строки, которые отвечают за отображение баннера. Обычно это `<img>`, `<a>` или `<iframe>` с атрибутами размера.

### Шаг 2 — Оберните баннер в контейнер

Добавьте `<div>` с параметрами CPMind вокруг вашего баннера. Замените значения параметров на свои:

```html
<div
  data-cpmind-creative
  data-tag-uuid="ВАШ_TAG_UUID"
  data-campaign-id="ВАШ_ID_КАМПАНИИ"
  data-creative-id="ВАШ_ID_БАННЕРА"
  data-creative-type="banner_static"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: ШИРИНА_БАННЕРА_px; height: ВЫСОТА_БАННЕРА_px;"
>
  ВАШ БАННЕР ЗДЕСЬ
</div>
```

**Важно:** `data-tag-uuid` — обязательный параметр, выдается командой CPMind вместе с доступом к панели аналитики. Без него или с неверным значением показы не будут засчитаны. Укажите в `style` точные размеры вашего баннера в пикселях.

### Шаг 3 — Добавьте подключение тега

В конце HTML-страницы, перед закрывающим тегом `</body>`, добавьте (точный адрес, включая номер версии, выдается командой CPMind):

```html
<script async src="https://app.cpmind.tech/tag/cpmind-tag_v{N}.min.js"></script>
```

Если на странице несколько баннеров — скрипт все равно подключается **один раз**. Если команда CPMind заменит вашу версию на новую (например, после улучшения точности измерений) — она сообщит вам новый адрес скрипта. Подключенный ранее адрес продолжит работать, пока вы не замените его сами.

### Шаг 4 — Сохраните и проверьте

Сохраните файл, опубликуйте изменения на сайте, откройте страницу в браузере. Визуально ничего не должно измениться — баннер выглядит так же, как раньше.

### Шаг 5 — Убедитесь, что данные поступают

Откройте страницу в браузере, подождите несколько секунд, посмотрите на баннер, закройте вкладку. Затем войдите в панель аналитики `https://app.cpmind.tech` — в таблице должна появиться новая запись.

## Параметры тега

| Параметр | Обязательный | Что указывать |
|---|---|---|
| `data-tag-uuid` | да | Уникальный идентификатор вашего аккаунта, выдается командой CPMind. Без него показы не засчитываются |
| `data-campaign-id` | да | Название рекламной кампании. Используйте латинские буквы, цифры и `_`. Например: `autumn_promo_2026` |
| `data-creative-id` | да | Уникальное название конкретного баннера. Например: `banner_728x90_autumn_v1` |
| `data-creative-type` | да | Тип баннера: `banner_static`, `banner_gif` или `banner_html5` |
| `data-endpoint` | да | Всегда указывайте: `https://app.cpmind.tech/api/collect` |
| `style` (width, height) | да | Точные размеры баннера в пикселях |
| `data-debug` | нет | Только для тестирования командой CPMind: `data-debug="true"` |

**Правила именования** `campaign_id` и `creative_id`:
- Только латинские буквы, цифры и символ `_`
- Без пробелов, без кириллицы
- Максимум 100 символов
- Регистр важен: `Summer_Sale` и `summer_sale` — разные кампании

## Типы баннеров

### banner_static — статическое изображение

Обычная картинка в формате JPG, PNG или WebP.

```html
<div
  data-cpmind-creative
  data-tag-uuid="UUID_вашего_тега"
  data-campaign-id="kampania_2026"
  data-creative-id="statichny_banner_728x90"
  data-creative-type="banner_static"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: 728px; height: 90px;"
>
  <a href="https://example.ru" target="_blank" rel="noopener">
    <img src="/banners/kampania_2026_728x90.jpg" width="728" height="90" alt="Реклама" />
  </a>
</div>
```

### banner_gif — анимированный баннер

GIF-анимация. Интеграция идентична статическому баннеру, только `data-creative-type="banner_gif"`.

```html
<div
  data-cpmind-creative
  data-tag-uuid="UUID_вашего_тега"
  data-campaign-id="kampania_2026"
  data-creative-id="animirovannyy_banner_728x90"
  data-creative-type="banner_gif"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: 728px; height: 90px;"
>
  <a href="https://example.ru" target="_blank" rel="noopener">
    <img src="/banners/kampania_2026_728x90.gif" width="728" height="90" alt="Реклама" />
  </a>
</div>
```

### banner_html5 — HTML5-баннер

Интерактивный баннер в виде iframe или встроенного HTML. Используйте `data-creative-type="banner_html5"`.

```html
<div
  data-cpmind-creative
  data-tag-uuid="UUID_вашего_тега"
  data-campaign-id="kampania_2026"
  data-creative-id="html5_banner_728x90"
  data-creative-type="banner_html5"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: 728px; height: 90px;"
>
  <iframe
    src="https://ваш-сайт.ru/banner/index.html"
    width="728"
    height="90"
    scrolling="no"
    frameborder="0"
    style="display:block;"
  ></iframe>
</div>
```

**Примечание для HTML5-баннеров в iframe:** если баннер загружается с другого домена (cross-domain iframe), сигнал S3 (скорость скролла) будет недоступен — это нормальное поведение, вес S3 автоматически перераспределится на другие сигналы.

## Несколько баннеров на одной странице

Если на странице несколько рекламных блоков, обоните каждый в отдельный контейнер с уникальным `data-creative-id`. Скрипт подключается **один раз**.

```html
<!-- Первый баннер -->
<div
  data-cpmind-creative
  data-tag-uuid="UUID_вашего_тега"
  data-campaign-id="kampania_2026"
  data-creative-id="banner_header_728x90"
  data-creative-type="banner_static"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: 728px; height: 90px;"
>
  <a href="https://example.ru"><img src="header-banner.jpg" width="728" height="90" /></a>
</div>

<!-- Контент страницы... -->

<!-- Второй баннер -->
<div
  data-cpmind-creative
  data-tag-uuid="UUID_вашего_тега"
  data-campaign-id="kampania_2026"
  data-creative-id="banner_sidebar_300x250"
  data-creative-type="banner_static"
  data-endpoint="https://app.cpmind.tech/api/collect"
  style="width: 300px; height: 250px;"
>
  <a href="https://example.ru"><img src="sidebar-banner.jpg" width="300" height="250" /></a>
</div>

<!-- Один скрипт в конце страницы -->
<script async src="https://app.cpmind.tech/tag/cpmind-tag_v{N}.min.js"></script>
```

Каждый баннер будет отслеживаться независимо и записываться как отдельный импрешен. `data-tag-uuid` одинаков для обоих баннеров — это идентификатор вашего аккаунта, не конкретного баннера.

## Проверка — данные поступают

### Способ 1 — через панель аналитики

1. Разместите тег на странице
2. Откройте страницу в браузере
3. Посмотрите на баннер несколько секунд
4. Закройте вкладку
5. Откройте `https://app.cpmind.tech` и войдите
6. В таблице должна появиться новая запись с вашим `campaign_id`

Запись появляется в течение нескольких секунд после закрытия вкладки.

### Способ 2 — через инструменты разработчика браузера

Если вы умеете пользоваться DevTools:

1. Откройте страницу с тегом
2. Нажмите F12 (или Ctrl+Shift+I / Cmd+Option+I на Mac)
3. Перейдите на вкладку **Network** (Сеть)
4. Закройте вкладку страницы

В списке запросов появится запрос к `impressions` на домен `app.cpmind.tech`. Тип запроса — **маячок** (beacon). Это означает, что данные успешно отправлены.

## Часто задаваемые вопросы

**Баннер перестал кликаться / изменился внешний вид**

Проверьте, что размеры в `style="width: ...; height: ...;"` совпадают с реальными размерами баннера. Контейнер `<div>` не должен обрезать содержимое.

**Данные не появляются в панели**

Убедитесь, что:
- на сайте включен HTTPS (адрес начинается с `https://`)
- `data-tag-uuid` указан без опечаток — значение выдано именно командой CPMind для вашего аккаунта, не скопировано из чужого примера
- в `data-endpoint` указан именно `https://app.cpmind.tech/api/collect` (не `http://`)
- адрес скрипта совпадает с тем, что выдала команда CPMind, включая номер версии (`cpmind-tag_v{N}.min.js`)
- скрипт подключен внизу страницы перед `</body>`
- вы закрыли или переключили вкладку после просмотра баннера (данные отправляются при уходе со страницы)

**Влияет ли тег на скорость сайта?**

Нет. Тег подключается с атрибутом `async` — браузер загружает его параллельно с остальным контентом, не блокируя рендеринг страницы.

**Нужно ли менять тег при обновлении баннера?**

Если меняется содержимое баннера (другое изображение) — используйте новый `data-creative-id`. Сам контейнер и скрипт остаются теми же. Если меняется кампания — меняйте `data-campaign-id`.

**Что такое `data-tag-uuid` и можно ли его менять самостоятельно?**

Это идентификатор вашего аккаунта в системе CPMind — один на все ваши баннеры и кампании, выдается командой CPMind при подключении. Менять его самостоятельно не нужно и не следует: значение привязывает все ваши показы к вашим данным в панели аналитики. Если вы потеряли или не получили это значение — обратитесь к команде CPMind.

**Команда CPMind сообщила, что нужно обновить адрес скрипта тега — что это значит?**

Иногда команда CPMind улучшает точность измерений тега (например, точнее определяет скорость скролла или взаимодействие с баннером на мобильных устройствах). Это оформляется как новая версия файла тега с новым адресом (`cpmind-tag_v{N}.min.js`). Старый адрес продолжает работать без изменений — обновление не происходит автоматически. Чтобы получить улучшения, замените `src` в строке `<script async src="...">` на новый адрес, который вам сообщит команда CPMind. Остальной код на странице (контейнер баннера, `data-tag-uuid` и другие параметры) менять не нужно.

**Работает ли тег на мобильных устройствах?**

Да. Тег автоматически определяет тип устройства и активирует соответствующие обработчики: для десктопа — отслеживание мыши, для мобильных — отслеживание тапов, свайпов и зума.

**Что происходит, если пользователь не закрыл вкладку, а просто ушел на другой сайт?**

Данные отправляются в трех случаях: клик по баннеру, переключение/сворачивание вкладки, закрытие вкладки или браузера. Во всех случаях накопленные данные будут отправлены.

**Нужно ли согласие пользователя (GDPR, 152-ФЗ)?**

Тег не собирает персональные данные в смысле закона: нет имен, email, телефонов, IP-адресов, идентификаторов пользователей. Собираются только агрегированные поведенческие метрики одного сеанса просмотра баннера. Юридическую консультацию по вашей конкретной ситуации рекомендуется получить у специалиста.

## Примеры для разных CMS

### WordPress

В WordPress для добавления HTML-кода на конкретную страницу используйте блок "Пользовательский HTML» в редакторе Gutenberg, или вставьте код напрямую в шаблон страницы через редактор тем (Внешний вид → Редактор → нужный шаблон).

Для добавления скрипта в конец `</body>` на всех страницах — используйте плагин "Insert Headers and Footers» или добавьте в `functions.php` темы:

```php
function cpmind_tag_script() {
    echo '<script async src="https://app.cpmind.tech/tag/cpmind-tag_v{N}.min.js"></script>';
}
add_action('wp_footer', 'cpmind_tag_script');
```

### Тильда (Tilda)

На Tilda добавление произвольного HTML возможно через блок T123 (HTML-код). Поместите в него контейнер баннера с параметрами. Скрипт добавьте через Настройки сайта → Еще → Добавить HTML-код → вставьте в "Код перед </body>».

### Bitrix

В Bitrix используйте компонент `bitrix:main.include` или добавьте код через редактор шаблона в разделе "Сайты и магазины» → "Шаблоны сайтов». Скрипт разместите в `footer.php` вашего шаблона.

### Чистый HTML

Если сайт на чистом HTML — просто откройте HTML-файл в текстовом редакторе и добавьте описанные фрагменты кода в нужное место.
